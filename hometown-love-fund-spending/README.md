# 고향사랑기금 지출 분석 (2023~2026.10)

데이터팝콘 테크블로그 글 「고향사랑기금은 정말 안 쓰고 있을까?」(https://datapopcorn.ai/blog/hometown-love-fund-spending)의 재현 패키지입니다.

- `hometown_love_fund_analysis.ipynb`: Colab에서 `런타임 → 모두 실행`하면 글의 숫자와 차트 6개를 다시 만듭니다. API 키가 필요 없습니다.
- `data/QWGJK_gohyang_<연도>_<집행일자>.jsonl`: 행정안전부 지방재정365 OpenAPI 「세부사업별 세출현황」을 연도별로 전수(46.6만~48만 행) 스캔해, 회계명에 '고향사랑'이 있거나 사업명에 '고향사랑'·'답례품'이 있는 행만 남긴 원자료입니다. 조회일 2026-10-28.
- `data/lofin_JFIED_2024.json`: 지방재정365 재정자립도(최종) 2024
- `data/laf_list.csv`: 지자체 243곳 목록(2024~2025 기준 코드)
- `data/crosscheck_disclosure_vs_lofin.csv`: 지자체가 홈페이지에 공개한 「고향사랑 기부금 접수·운용 현황」 원문 14건과의 대조
- `data/search_volume.csv`: 네이버 검색광고 키워드도구 월간 검색수(2026-10-28 조회)

출처 표기: 행정안전부 지방재정365(공공누리 제1유형). 분류(주민사업·포괄 기금사업·운영·답례품·예치)는 세부사업명을 기준으로 한 추정입니다.
