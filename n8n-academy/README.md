# n8n Academy 🍿

듀오링고에서 영감을 받은 **게임형 n8n 학습 웹서비스**입니다. 별도 서버·빌드 없이 `index.html` 하나로 동작합니다.

## 실행 방법

```bash
# 저장소 루트에서
python3 -m http.server 8000
# → http://localhost:8000/n8n-academy/
```

브라우저에서 `index.html`을 직접 열어도(file://) 동작합니다.

## 기능

- **학습 경로**: 5개 유닛 × 10개 레슨 (기초 개념 → 트리거 → 핵심 노드 → 표현식 → 에러 처리/실전 팁)
- **문제 유형 5종**: 객관식(노드 아이콘 문제 포함) · O/X · 빈칸 채우기 · 순서 배열(워크플로우 조립) · 짝 맞추기
- **게임 요소**: 하트 5개(오답 시 차감) · XP와 레벨 · 일일 스트릭 🔥 · 별점(정확도) · 오답 재출제(듀오링고 방식) · 효과음 · 컨페티
- **진행 저장**: `localStorage`(`n8n-academy-v1` 키)에 저장 — 계정/백엔드 불필요
- **키보드 지원**: `1`~`9` 보기 선택, `Enter` 확인/계속

## 구조

| 경로 | 설명 |
|---|---|
| `index.html` | 앱 전체 (마크업 + 스타일 + 커리큘럼 데이터 + 게임 로직) |
| `icons/` | n8n 노드 아이콘 SVG (`../n8n-cheatsheet/icons`에서 복사) |

## 커리큘럼 수정하기

`index.html`의 `UNITS` 배열이 커리큘럼 전체입니다. 문제 유형별 스키마:

```js
{ t: "mc",    q: "질문", img: "icons/….svg"?, opts: ["보기…"], a: 정답idx, why: "해설" }
{ t: "tf",    q: "명제", a: true|false, why: "해설" }
{ t: "blank", q: "문장 ___ 문장", tokens: ["후보…"], a: "정답토큰", why: "해설" }
{ t: "order", q: "지시문", seq: ["정답", "순서"], why: "해설" }
{ t: "match", q: "지시문", pairs: [["왼쪽", "오른쪽"], …] }
```

질문·해설 문자열 안에서 `` `코드` `` 는 `<code>`로 렌더링됩니다.

콘텐츠 출처: [`../n8n-cheatsheet`](../n8n-cheatsheet) (데이터팝콘 n8n 치트시트)

## 상표·저작권 고지

- **n8n**은 n8n GmbH의 상표입니다. 본 프로젝트는 n8n GmbH와 무관한 **비공식 학습 자료**이며, 공식 제품·공식 교육과정이 아닙니다.
- `icons/`의 SVG는 n8n 앱에서 추출한 공식 에셋이 아니라 **자체 제작한 단순 선(stroke) 스타일 그림**입니다.
- 게임 진행 방식(하트·XP·스트릭 등)은 일반적인 학습 게임 메커니즘으로, 특정 서비스의 그래픽·캐릭터·사운드·코드를 사용하지 않았습니다.
- 퀴즈 텍스트는 데이터팝콘이 자체 작성했습니다.
