# 클로드 레벨업 (Claude Level-Up)

듀오링고처럼 레벨을 하나씩 깨면서 클로드를 배우는 초보자용 학습 게임. 의존성 없는 단일 HTML 파일이라 `index.html`을 브라우저로 열기만 하면 됩니다.

## 커리큘럼

| 유닛 | 주제 | 레슨 |
|---|---|---|
| 1 | 클로드 첫걸음 | 클로드 소개 · 첫 대화 · 아티팩트&프로젝트 |
| 2 | 프롬프트 레벨업 | 3요소 · 단계별 요청 · 실전 활용 |
| 3 | 클로드 in 크롬 | 시작하기 · 안전 수칙 · 활용 시나리오 |
| 4 | 클로드 코드 | 소개 · 기본 사용법 · 심화(MCP·스킬·Git) |
| 👑 | 보스전 | 전 범위 랜덤 10문제 (전 레벨 클리어 시 해금) |

총 12레슨 + 보스전, 문제 60개 (객관식 / OX / 빈칸 채우기).

## 게임 요소

- **XP**: 문제당 10 XP, 무실수 클리어 시 +20 보너스
- **하트**: 레슨당 3개 — 틀리면 감소, 0이 되면 재도전. 틀린 문제는 큐 뒤로 돌아와 복습
- **별점**: 남은 하트 수(1~3개)로 기록, 레벨 해금 조건
- **스트릭**: 매일 학습 시 🔥 연속일 증가
- 진행 상황은 `localStorage`에 저장 (초기화 버튼 제공)
